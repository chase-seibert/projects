# Initial brainstorm

Create a GitHub project that lists interesting apps Chase has built, gives each one a screenshot, and links to the repository or static site. The portfolio should itself be a static GitHub Pages site, deploy automatically, and be easy to preview locally.

The first collection is, in order: Cookbook, Sideline Save, Chase Seibert Blog, Chase Sidekick, Calorie Tracker, Miclog Desktop, Remote Agent, Clipboard Markup, ICS Combine, CronTab Manager, and RSS Combine.

The first version should feel personal and curated rather than like a generic repository index. Cookbook leads the collection, product screenshots get generous space, and each description focuses on the problem the project solves.
