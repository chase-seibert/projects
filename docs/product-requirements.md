# Product requirements

- As a visitor, I want to quickly understand what Chase builds, so that I can decide which projects to explore.
- As a visitor, I want every project to have a strong visual, concise description, and working destination, so that the gallery feels useful rather than decorative.
- As a mobile visitor, I want the entire gallery to remain readable and easy to navigate, so that I can browse from any device.
- As the maintainer, I want project content to live in one small data structure, so that adding and reordering work is straightforward.
- As the maintainer, I want an automatic deployment after changes reach `main`, so that the live portfolio stays current.
- As the maintainer, I want a local preview and production build check, so that I can review changes before publishing.
